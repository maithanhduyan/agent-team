# Mode B — Owner run kit: install-dsh eval suite on Windows Sandbox (T14)

> **Who runs this:** the **owner** (you) — on your Windows laptop, in a
> **Windows Sandbox**. You do **not** need to understand code. The
> tester (QA) wrote the harness; you execute it and report results.
>
> **Why:** the fitness gate requires **100% pass** (SEC-GEPA-02) as the
> final evidence before an evolved `install-dsh` skill is merged. Mode A
> (offline, in the repo/CI) already runs the same suite deterministically;
> Mode B is the **real Windows** run that proves the suite behaves
> correctly on your machine (T17 E2E evidence + dataset refresh for T11).

---

## What you will produce

One JSON file (`mode-b-results.json`) that the harness writes for you,
plus a filled-in result form (below). Upload both to the task/PR.

## Steps (15–20 minutes)

### 1. Get the kit onto your laptop

- Make sure you have the agent-team repository on your laptop (or
  download just this folder from the PR):
  `agent-desktop/evolution/harness/`
- The two files you need are in `mode-b/`:
  - `run-mode-b.ps1` (the harness script)
  - this file (`owner-instructions.md`) and `result-form.md`

### 2. Open Windows Sandbox

- Windows Sandbox is a disposable Windows environment. Open it from
  the Start menu (type "Windows Sandbox") — it comes with Windows 10
  Pro/Enterprise/Education or Windows 11 Pro+.
- Copy the `harness/mode-b` folder into the sandbox (drag & drop, or
  paste into Explorer). Any folder works, e.g. `C:\Users\WDAGUtilityAccount\Desktop\mode-b`.

### 3. Run the harness

Open **PowerShell** inside the sandbox (right-click Start → "Windows
PowerShell" or "Terminal"). Then run:

```powershell
cd C:\Users\WDAGUtilityAccount\Desktop\mode-b
powershell -ExecutionPolicy Bypass -File .\run-mode-b.ps1
```

Or, if the script is blocked, run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\run-mode-b.ps1
```

### 4. Read the summary

The script prints a table like this:

```
[PASS] hp-install               happy-path
[PASS] hp-idempotency           happy-path
... (12 rows)
Fitness    : 1   (threshold 1.0)
Gate       : PASS
Result file: C:\...\mode-b\mode-b-results.json
```

- **Gate = PASS** → all 12 cases passed → upload the JSON + form.
- **Gate ≠ PASS** → some cases failed/skipped. **Do not edit the
  JSON.** Re-run once (occasional flake). If it still fails, fill the
  result form with the printed details and upload everything — the
  team needs to see the failure (that is real evidence too).

### 5. Fill the result form

Open `result-form.md` and fill in the fields (owner name, date, the
summary numbers from the console, the run id from the JSON). Copy the
whole filled form as a comment on the PR (or attach the files to the
Redmine issue).

### 6. Upload

Upload to the pull request / Redmine issue:

1. `mode-b-results.json` (generated by the harness — do not modify)
2. the filled-in `result-form.md`

## Notes & troubleshooting

| Symptom | What it means / what to do |
|---|---|
| "EFS support: False" and the three `efs-*` cases are SKIP | This sandbox volume has no EFS (Encrypting File System) support. Record it in the form — the junction/service/happy-path cases still ran. EFS cases will be re-checked on a volume that supports it. |
| Script blocked by policy | You already bypass it with `-ExecutionPolicy Bypass` (step 3). |
| `cipher.exe` not found | Extremely unlikely on Windows; re-run on a normal Windows Sandbox. |
| Gate = REJECT but all rows PASS | Contradiction → don't ignore; attach the JSON and console output as-is. |
| Sandbox closes and files are lost | Copy the JSON out of the sandbox **before** closing it (step 6). Windows Sandbox discards everything on close. |

## Security note (SEC-GEPA-08)

- Never paste API keys, tokens or passwords into the form or the
  console output you upload. The suite uses a **fake** credential
  (`OLD_HASH`/`NEW_HASH`); if you see anything that looks like a real
  secret in the output, redact it before uploading.
- Windows Sandbox is a **disposable** environment: anything you run
  here cannot touch your real machine (SEC-GEPA-01 boundary).
