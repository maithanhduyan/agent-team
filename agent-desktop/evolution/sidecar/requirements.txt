# MockLM/ProxyLM backends run the same loop (tests / CI / no-key mode,
# SEC-KEY-03). Pinning dspy here (build-time, CI only) records the
# exact artifact for replay (SEC-GEPA-11).
#

#   pip install --require-hashes -r requirements.txt
